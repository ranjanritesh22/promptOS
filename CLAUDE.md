# PromptOS

PromptOS is an AI Prompt Composer.

The project consists of:

- A Next.js web application
- A Chrome Extension

Both applications share the same:

- Prompt Engine
- Template Engine
- UI Components
- Utilities
- Types

The architecture should maximize code sharing while keeping each application independent where necessary.

The extension should work independently if the web app is unavailable.

The web app should be the primary product.

The extension should integrate with ChatGPT, Claude, Gemini, Cursor, Perplexity and other AI platforms.

Always prefer reusable packages over duplicated code.
